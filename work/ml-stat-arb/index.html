Machine-learning pairs trading for PropTech

Tests whether gradient-boosting pipelines built for building-energy time series can detect cointegration breakdowns between real-estate stocks and turn them into trading signals.

Type
Machine learning, quantitative finance
Stack
Python, pandas, statsmodels, scikit-learn, LightGBM, XGBoost, CatBoost
Data
Daily prices via yfinance, e.g. PLD and AMT
Code
ml-stat-arb

View the code on GitHub

Highlights

  • Pairs trading framed as anomaly detection on the spread
  • Lag, rolling-window and Savitzky-Golay features
  • Modular pipeline: loader, features, clustering, ensemble, backtest

This started while I was reproducing Prof. Chun Fu's workflows for the ASHRAE Great Energy Predictor III and LEAD competitions. Gradient-boosting machines with careful time-series features win those problems, and pairs trading is a kind of anomaly detection: you look for moments when the spread between two related assets breaks from its history. So I tested whether the same pipeline transfers to financial time series, using PropTech and REIT pairs such as Prologis (PLD) and American Tower (AMT).

Method

Prices are cleaned and turned into a feature matrix of time-lag features, ratios and differences, and rolling-window statistics. A Savitzky-Golay filter smooths microstructure noise while keeping the height of real peaks in the spread, which a moving average would flatten and delay. An ensemble of LightGBM and XGBoost models predicts the spread, and the trading logic enters when it moves beyond two standard deviations and stops out beyond three.

Engineering

The code is split into a data loader, feature builder, clustering step, model ensemble and backtester, configured from one YAML file. A notebook walks through the exploratory analysis, the smoothing and the model training.
